11 分钟上手

  1. 改内容
    点页面上任何文字直接改；点头像、二维码换成你自己的。不想一点点删示例，就点首页标题下的 从空白开始。
  2. 挑样式
    点底部的 外观定制，选一个「一键风格」，再按喜好微调。
  3. 导出分享
    点 预览 确认效果，然后 导出图片 发到群里或社交平台。
所有内容自动保存在你自己的浏览器里，不需要注册，也不会上传到服务器。

2统一操作规则

编辑器里的每样东西都按下面几条规则操作，学会一次就能用遍全站：

想做什么怎么做
改文字直接点文字。选中一段文字会出现工具条：加粗 / 斜体 / 下划线 / 删除线、A+ 大字、五种颜色、清除格式。
换图片直接点图片（头像、二维码、图片墙里的图）。
设置某张卡片或某个区块鼠标移上去（手机上点一下），右上角出现 ⚙：宽度、颜色、位置等都在里面。
删除同一位置的 ×。标签、图片的小 × 在角落，信息项的 × 紧跟在文字后面。
添加所有添加按钮都是虚线框的 + 添加…。
调整顺序卡片和区块：⚙ 里的「上移 / 下移」。电脑上也可以拖动卡片顶部的 ⠿。
删错了删除不会弹确认框，底部会出现 撤销，或按 Ctrl+Z（Mac：⌘+Z）。
改整体样式底部 外观定制。只改一张卡片：那张卡片的 ⚙。
看最终效果底部 预览，所有编辑按钮都会隐藏；按 Esc 退出。

3卡片

添加卡片

点底部 添加卡片，按用途选一个模板。最后一行还有空位就放在空位里，否则放到最下面，页面会自动滚过去：

  • 身份卡：大头像 + 一行「生日 | MBTI | IP」+ 一句标语。
  • 关于我（2 列宽）、常规卡片（1 列宽）。
  • 我的推：心肝（醒目）和好感（描边）分两档，最后留一个推图位。
  • 属性：CP 立场、同担态度等。
  • 雷点 / NG：红色标签列出雷点，再补一句说明。
  • 扩列请：想找什么样的朋友、加好友的规矩，加上二维码。
  • 推图 / 图片墙：放多张图片。个人信息：头像 + 信息列表 + 二维码。

模板里灰色虚线的是 示例标签：加上你自己的标签后会自动消失，预览和导出时也不显示，不用手动删。

从空白开始

首页展示的是站长本人的扩列条，包括头像和二维码。想制作自己的，点首页标题下的 从空白开始（「更多配置」里也有）：换成占位头像和二维码，只留一张身份卡和一张关于我，主题和外观设置不变。点错了可以撤销。

卡片设置

卡片右上角 ⚙ 里可以改：宽度（1 / 2 / 3 列）、这张卡片的背景色、居左或居中、是否显示标题、上移 / 下移。

4区块与标签

每张卡片由若干「区块」组成，可以自由组合、上下调整。点卡片底部的 + 添加区块，面板按 文字 / 个人信息 / 标签 / 图片 分组，每个选项的缩略图就是插入后的样子：

上色和 A+ 只修改选中的文字。建议只强调几个关键词，正文保留普通字号；清除格式也只作用于当前选区。

标签

  • 点 + 添加标签，输入后按 Enter。输入框会保持打开，可以连续添加；按 Esc 或点别处结束。
  • 一次添加多个：用顿号、逗号或分号隔开，比如「初音未来、镜音铃、巡音流歌」会变成三个标签（斜杠不拆，「BG/GL」还是一个）。
  • 用拼音、日文输入法时，按回车确认候选词不会误添加。
  • 点标签文字可以直接改；鼠标移到标签上，右上角的小 × 删除。
  • 标签区块的 ⚙ 里可以选 配色：默认、醒目（实心，适合心肝 / 本命）、描边（适合好感）、雷点（红色带 ✕，适合 NG）。

5头像、二维码、图片墙

头像、信息、二维码都是独立区块

「个人信息」卡片由 头像、信息列表、二维码 三个区块组成，每个都能单独删除、移动或设置。想要一张只有头像和昵称的卡片？删掉信息列表和二维码，再加一个 标题 区块即可。

  • 换头像：点头像选择图片，会自动裁成正方形并压缩。所有头像区块显示的是同一张头像。
  • 二维码用链接生成：在二维码下方的输入框粘贴 QQ 名片、B 站主页等链接。
  • 二维码用图片：微信二维码等无法用链接生成的，直接点二维码上传图片。想换回链接：二维码区块的 ⚙ → 二维码来源 → 链接生成。
  • 不要二维码 / 头像：点该区块右上角的 × 删除（可以撤销）。以后想加回来：+ 添加区块 → 个人信息 → 二维码。

图片墙（推图）

  • + 添加图片 可以一次选多张。
  • 点某张图片可以替换它；鼠标移上去会出现 ‹ › 调顺序、T 加图片说明、× 删除。
  • 区块的 ⚙ 里可以设置每行几张（1–4），以及「方形裁切」：图片比例不一时开启，排列更整齐。

6外观定制

点底部 外观定制 打开侧边面板，所有改动实时生效：

  • 一键风格：经典、玻璃、极简、手账、夜间。先选一个最接近的，再微调。
  • 主题与强调色：强调色会影响标签、分割线等的颜色。赛博朋克主题使用固定配色。
  • 页面背景：跟随主题、纯色、渐变，或上传背景图。背景图可以选择铺满、完整或平铺，再加一层蒙版让文字更清楚。纯色和渐变上还可以叠 波点 / 条纹 / 格子 图案。
  • 卡片：底色、不透明度（调低就是毛玻璃效果）、圆角、阴影、边框、文字颜色。
  • 间距与文字：卡片之间的间距、卡片内边距、行高、字号缩放、字体（包括几种中文艺术字体）。快乐体、毛笔、手写这类字体只用在标题上，正文保持清楚易读。
  • 显示内容：副标题、页脚可以关掉。头像和二维码是区块，不需要就直接删除。
背景较深时，标题和文字会自动变成浅色。给单张卡片设置深色底色时，那张卡片的文字也会自动变浅。

7预览与导出

点底部 预览：所有编辑按钮、输入框、添加按钮都会隐藏，看到的就是导出的样子。预览时底部会显示快捷导出按钮。

导出方式适合
导出图片（PNG）发 QQ 群、朋友圈。固定按电脑三列排版，3 倍清晰度。
导出竖版图片（PNG）手机上看、发到手机上的社交平台。所有卡片排成一列的长图，顺序和电脑上从左到右、从上到下一致。
导出 HTML一个独立网页文件，可以挂到自己的网站，或直接用手机浏览器打开（在手机上会自动变成单列）。
导出配置（JSON）备份，或换设备继续编辑。用 导入配置 恢复。

导出、导入、语言切换都在底部的 更多配置 里。

9AI 一键生成

点底部 AI 一键生成，像聊天一样回答几个问题，AI 会帮你整理成卡片。

准备 API Key

  • 推荐免费的 Google Gemini：打开 Google AI Studio，登录后点「Create API key」，复制粘贴到 AI 面板里的输入框即可。
  • 也可以用 OpenAI、Anthropic 或兼容 OpenAI 格式的其他接口：点面板里的 使用 OpenAI / Anthropic / 其他接口（或右上角设置）。自定义接口需要允许浏览器跨域访问（CORS）。
  • Key 只保存在你的浏览器里，请求直接发给服务商，不经过本站服务器。
使用 Gemini 免费额度时，对话内容可能被 Google 用于改进产品。请不要在对话里提供真实姓名、手机号、住址等隐私信息，AI 也不会把这些写进卡片。

聊天与生成

  • AI 每次只问一两个问题，问题下面会有几个 快捷选项，点一下就能回答，也可以自己打字；不想回答的直接说跳过。它只会用你说过的信息，不会编造年龄、性别、属性等内容。
  • 它会按扩列条的常见结构来整理：头像 + 一行「生日 | MBTI | IP」、在玩、推（心肝 / 好感分开）、属性、NG、扩列请 + 二维码，没聊到的部分就不生成。卡片宽度会自动排好，每一行都是满的。
  • 聊到差不多时点 直接生成。旁边可以选择 替换全部（用生成结果替换现有卡片和标题，并按你说的感觉套用一键风格和主题色）或 追加到末尾（保留现有卡片和外观，把新卡片加在后面）。
  • 生成后可以点 换个风格 在五种一键风格之间切换，内容不变，也不会再请求 AI。
  • 生成的卡片会先放一个占位头像和占位二维码，头像、二维码和推图要你自己上传：关掉面板后点对应的位置就行。
  • 不满意可以点面板里的 撤销这次生成，或用底部的撤销提示 / Ctrl+Z。
  • 不小心关掉面板也没关系，在当前标签页里重新打开，聊天记录还在。

10数据与备份

  • 内容自动保存在当前浏览器（每次修改后约 0.5 秒）。换浏览器、换设备，或清理浏览器数据后就看不到了，记得定期用 导出配置 备份。
  • 导入配置 支持本站导出的 JSON，也支持 Tintro（瀑布流自介生成器）导出的配置。
  • 浏览器存储空间有限，大约 5MB。图片会自动压缩，但如果放了特别多图片，页面顶部可能会出现「存储空间不足」的红色提示。这时请删掉一些图片，或先点提示里的 下载备份。
  • 想从头开始：更多配置 → 恢复默认模板，同样可以撤销。
如果页面打不开、一直报错，出错页面上有「下载数据备份」和「清空本地数据」两个按钮：先备份，再清空即可恢复使用。

按键作用

12常见问题

手机上怎么调整卡片顺序？

点一下卡片，右上角会出现 ⚙，在里面点「上移 / 下移」。手机上不能拖动卡片，这是为了不打乱电脑版的排版。

导出的图片里头像是空白的？

默认头像存放在第三方服务器上，浏览器不允许把它画进图片里。换成你自己上传的头像就正常了。

换了字体但看起来没变化？

中文艺术字体需要联网加载，第一次使用会慢几秒。如果网络限制了字体服务，就会显示系统默认字体。另外，快乐体、毛笔、手写这类字体只用在标题上，正文不会变。

赛博朋克主题下卡片颜色设置不生效？

赛博朋克主题有固定的卡片样式。想完全自定义卡片颜色，请切回「默认」主题。

别人能看到我编辑的内容吗？

不能。内容只保存在你自己的浏览器里，只有你导出并发出去的图片或网页才会被别人看到。

只想要头像（或只要标题），不要信息和二维码？

它们都是独立区块：鼠标移到信息列表、二维码上，点右上角 × 删除即可；需要标题就 + 添加区块 → 标题。

怎么把卡片标题去掉？

卡片右上角 ⚙ → 关闭「显示标题」。
